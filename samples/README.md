# sampleCombo

这是作者于 2026-11-10 明确授权发布的 default 连招快照。仅将文件名改为 `sampleCombo.combo`，二进制内容与当时的原文件完全相同；原 default 未修改。

运行安装器选择「安装完整版」会自动安装，也可选择「安装示例连招 sampleCombo」单独安装。文件位于 PBZ.exe 旁的 `combos` 文件夹。进入游戏后在 F10 → 招式派生 → 文件列表选择 `sampleCombo`；安装器不会改变当前选中的文件。

已有同名且内容不同的文件会保留，新示例另存为 `sampleCombo_bundled_<校验码>.combo`；继续同名冲突时追加编号。安装器不会覆盖 default。建议在编辑示例前「另存为」自己的名字。

手动安装：把本目录下的 `sampleCombo.combo` 复制到 PBZ.exe 旁的 `combos` 中。若同名文件已经存在，请先改名保存自己的版本。

示例文件哈希（SHA-256）：`82c238b13079c0ce0d33eed0c0637601a130ff134ca45f03b1a747600edcb385`。
