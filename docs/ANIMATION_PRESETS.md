# 骨骼变换与女性动画预设

本文面向调试角色动作、制作招式派生的玩家与维护者。它在原动画上增加骨骼调整，不会生成一套新的动作资源。

## 设计依据

“女性预设”是可修改的动作风格起点，不是所有女性角色应遵守的统一动作标准。这里的需求是**胯部**，不是跨步。

《绝区零》制作人李振宇的原始访谈描述了角色背景、原画、动画与战斗设计团队共同决定动作的过程，还会进行表演并拍摄参考。访谈没有公开胸部或臀部模拟算法，因此本项目不会把自己的弹簧参数称为《绝区零》的实现。[制作人访谈，2025-06-06](https://www.dbltap.com/features/zenless-zone-zero-zhenyu-li-interview-zzz-season-2)

《守望先锋 2》动画团队先确定角色的经历和性格，再打磨待机、移动、主要攻击等高频动作，并通过反复试玩修正轮廓和节奏。这意味着预设需要在普通移动和战斗中都可读，不能只在单个展示动作里成立。[Blizzard 动画团队原文](https://news.blizzard.com/en-us/article/24239492/weekly-recall-animation-station)

Animation Mentor 的步行动画教程将骨盆的重心转移、胸腔的反向旋转、身体各部分的延迟跟随分开处理，并要求消除滑步和膝盖跳变。本项目参考这些身体力学原则；不会因为需求中的笔误额外改变步幅。[Jason Martinsen 教程](https://www.animationmentor.com/blog/tutorial-animating-human-walk-cycle/)

Epic 的 Spring Controller 文档分别提供刚度、阻尼、最大位移和瞬移重置阈值。本项目采用同类可解释参数来限制惯性运动；当前实现是 MOD 内部的确定性解算，不是调用该动画节点，也未训练 ONNX。[Epic 官方文档](https://dev.epicgames.com/documentation/en-us/unreal-engine/animation-blueprint-spring-controller-in-unreal-engine)

## 当前实现

参考 [XTGMods / UUEPBS](https://github.com/XTGMods/UUEPBS) 的操作设计，骨骼页和节点详细页提供「简化体型」与「骨骼详情 / 动态」两种视图。简化视图仅列出当前骨架实际匹配的部位，局部 XYZ 缩放可拖动滑杆或输入 0.1–3 倍；左右部位一起设置，修正骨链通过父级继承，不对所有后代重复叠乘。惯性、女性预设及节点预览继续使用同一组参数。

详细视图新增仅显示已调整行、重置此行、清空本组，以及三种子骨骼模式：继承变换和缩放；跟随形状但保持尺寸；仅改变当前骨骼并保留后代姿势。旧存档没有子骨骼模式时按继承处理。

镜像按钮按参考姿势转换两侧骨骼轴，镜像位移、旋转和缩放，保留动态参数。首次点击会开启骨架读取；就绪后再次点击应用。只认实际存在的 `_l` / `_r` 配对。若非均匀缩放在两侧参考轴之间需要剪切，界面拒绝镜像，不给出看似正确的近似结果。

这不是 UUEPBS 二进制或完整功能移植：当前没有它的 Morph 编辑、通用游戏扫描或皮肤系统。复用的是公开功能设计，PBZ 实现仍使用已有的节点、预览和组件钩子。原项目自身未找到授权许可证，README 的 MIT 属于 Dear ImGui；来源署名与核查结果随发行包附带，见 [第三方说明](../THIRD_PARTY_NOTICES.md)。

独立“骨骼变换”页保存全局参数。“骨骼变换”节点与加速节点接受相同类型的连接，一组最多 32 行。每行可配置局部位移、XYZ 旋转、缩放和动态模式。节点详细编辑窗支持多行增删、启停、骨骼名选择及数值滚轮调整；编辑后点击“应用当前行”。节点卡片显示前两根骨骼及总数量。

启用的节点参数优先于全局参数。招式预览接收相同节点参数，并按预览角色自己的骨架匹配。缺失骨骼会跳过，不能靠修改骨骼名称凭空增加蒙皮权重。

女性预设包含以下部分：

| 部分 | 行为 | 调整重点 |
| --- | --- | --- |
| 胯部 / 骨盆 | 从原动画骨盆转动提取小幅附加转动 | 保留重心节奏，避免持续无来源摆动 |
| 臀胯整体跟随 | 对骨盆增加低强度惯性，默认每轴最多 0.35 cm | 没有独立臀部骨骼时仍有整体跟随；躯干也会随骨盆移动 |
| 胸腔 | 对骨盆附加转动做适量反向转动 | 保持躯干层次和战斗姿态 |
| 胸部 | 在存在对应骨骼时，按动作加速度产生受限惯性跟随 | 强度、位移上限、频率、阻尼 |
| 臀部 | 在存在独立臀部骨骼时，使用同一惯性模式 | 先确认实际骨骼与蒙皮；缺失时明确显示并跳过 |

“保留腿部原姿势”会保持大腿链和脚部 IK 链的原组件空间姿势，减少骨盆调整带来的脚部漂移。需要直接修改腿部骨骼时关闭此项。它不是地形脚部 IK 或完整接触约束。

关闭骨骼补充时，已核对的 Yuu 身体具有 `breast_l` / `breast_r`；主角和多种 BOSS 不具备相同骨骼。已检查的样本尚未找到 `butt_l` / `butt_r`；此时保留骨盆驱动的臀胯整体跟随，独立臀部行跳过。若需要独立软组织形变，需要选择角色实际存在的臀部骨骼，或在资产制作阶段补充骨骼与蒙皮。不能把“预设里有这一行”当作该模型已实现独立臀部形变。

## 存档与运行边界

全局参数位于 `PBZDebugMenu.ini` 的 `BoneMotion` 区段；节点参数随当前自定义连招文件保存。旧版本会把新节点读成不接执行线的间隔，忽略它的修饰连接，并保持其他节点下标。

运行端核对支持版本的原生函数字节后，仅替换目标组件自己的虚函数表副本，在姿势完成前施加调整。不会修改共享虚表、UE 源码或引擎 DLL。每次使用新姿势作为基础，跳过无新姿势的缓冲区，并对缓存姿势防止重复叠加。关闭后恢复，换模型后重新匹配。

惯性采用有界子步长，遇到瞬移或长时间停顿重置。可解释的参数已能覆盖目前需求，因此暂不引入训练数据、ONNX 模型或额外推理依赖。

## 验证范围

离线骨骼算法 10549 项、隐藏界面 1967 项及隔离保存压力测试 423 项通过。Steam 脚本检查了主角、沐小葵、玉妖、火流星的启停及外观恢复；玉妖两招在预设开启时运行，并进行了本地替身骨骼对照。节点施放记录到 10 cm 的调整，预览独立只读采样为 9.998–10.013 cm，关闭后为 0.0007–0.0084 cm。短窗口详情滚动、保存回读及连续页面切换也已检查。

这些是数值、生命周期和界面布局验证，不代表动画风格、衣物穿插或全部技能已通过视觉验收。WeGame 仅安装相同 DLL，未实机验证。具体日志与限制见本轮验证报告。


## 骨骼选择与调试

骨骼选择器使用自绘下拉列表，上方搜索框按名称筛选，不区分大小写。表情、眼球、下颌、舌头等骨骼不进入选择列表；头、颈和身体骨骼保留。旧存档已有的表情骨骼行不会被静默删除，但不能从新选择器再次添加。

切换到「骨架调试」页，勾选「骨骼调试 · 显示完整骨架」后显示实时组件空间骨架，自动缩放到全身范围。正面、侧面、背面按钮及滚轮可转向；点击骨骼可选中它，底部显示名称与坐标。拖动自绘滑条可实时预览，松手保存；精确输入数值后点击「应用当前行」。滑条支持方向键、Home / End 和滚轮；Shift + 方向键可微调。技能预览存在时，调试视图切换到预览角色。此视图显示骨架线条，不是角色网格渲染器。

## 原生女性骨骼迁移调查

对原始 cooked 身体资源进行了只读解析：Yuu 为 1088 根、MuXiaoKui 为 1090 根、Hun_Body_Simple 为 264 根参考骨骼；运行时还可能加入虚拟骨骼，因此数量可不同。Yuu 的 `breast_l`、`breast_r` 都挂在 `spine_05`，另有两个末端骨骼；主角的身体没有这四根骨骼。三个样本未发现以 butt/glute 命名的独立臀部骨骼。`thigh_bck` 属于大腿修正链，尚未验证其权重范围，不能当作独立臀部骨骼。

已导出四根胸部候选骨骼的参考变换及父级关系，未将它们写入主角资源。真正添加需要一起重建身体 SkeletalMesh 的参考骨架、各 LOD 的骨骼映射和蒙皮权重，检查 USkeleton、逆绑定矩阵及布料/物理/DNA 的兼容性，再用匹配游戏的资源流程烘焙。仅追加骨骼名不能驱动现有顶点；该调查描述原生资源。现在可选的 PBZSoftBones 包已为现有角色身体追加四根实际带权重的骨骼；用法与验证边界见 [胸臀骨骼补充](SOFT_BONES.md)。没有修改 UE 引擎。

## 替身头发

联机页的「替身头发 / Puppet hair」默认选择 Groom，可切换到发片。设置保存于 `PBZDebugMenu.ini` 的 `[NetPuppet] HairMode`：0 为 Groom，1 为发片。选择只作用于替身，不更改主角的全局头发模式。

缺少来源 Groom 时，尝试从游戏原有蓝图加载与身体绑定目标完全一致的 Groom 部件；整套刘海、发顶、马尾和发尾都会保留。没有匹配资源时回退到发片。头发、眉毛、睫毛、胡须分别处理，合并眉睫发片需要完整替代资源才隐藏；发带和帽子保留。无需额外 pak。


## 分区编辑

编辑器分为「体型」「骨骼」「预设」「状态」「骨架调试」五页，保留工具箱原有配色。「体型」按身体部位调整；「骨骼」上方搜索和选择调整行，下方按缩放、旋转、位移、动态四个折叠区修改。自绘滑条中央显示数值，默认隐藏独立输入框；勾选「数值输入」后可精确编辑。缩放支持「整体大小」同步调整 XYZ，每个参数区都有独立重置按钮。女性预设放在「预设」，胸臀补充开关及运行信息放在「状态」。相同骨骼的不同动态行分别保留，可删除单行、重置单行或清空本组；镜像按参考骨架计算。

节点详情与独立页共用此编辑器。拖动期间不写节点文件，松手提交一次；技能预览接收当前拖动值。骨骼补充开关是全局设置，不写入节点，也不改变 `default.combo`。
