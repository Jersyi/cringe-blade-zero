# 可选胸臀骨骼补充

在「骨骼变换 → 状态」页勾选「启用胸臀骨骼补充 · 当前角色与技能预览」。该开关默认关闭，保存于 DLL 旁 `PBZDebugMenu.ini` 的 `[BoneMotion] Supplement=0/1`。开关控制网格补充；顶部「启用」控制变换与动态，两者独立。

## 安装与关闭

退出游戏，将配套资源目录复制到 `version.dll` 旁：

```text
PBZ.exe
version.dll
PBZSoftBones/
  PBZSoftBones.pak
  PBZSoftBones.utoc
  PBZSoftBones.ucas
```

三文件需保持同一版本，并搭配本次修复后的 DLL。2026-11-10 早期补充包保留了旧渲染蒙皮数据，可能出现骨骼数值变化但模型不变，需更新为 `PBZSoftBones_20261110_r2.zip`。不要放入游戏原生 Paks 目录，不要改名为其他补充包。Steam / WeGame 使用同一 DLL 和同一组资源。缺包或当前身体未收录时保留原网格，状态区显示原因；不会用不存在的骨骼名冒充补齐。

关闭开关会移除补充显示组件、恢复源网格的蒙皮显示和动画更新设置。若要删除资源，先关闭开关并退出游戏，再删除 `PBZSoftBones` 目录。游戏更新后需同时重新核对 DLL 和资源序列化格式。

## 覆盖范围

当前包包含 69 个不同身体资源，覆盖现有 75 个角色外观条目及主角 `Hun_Body_Simple`，包括沐小葵一、二阶段。按完整原始资源路径匹配，火流星两阶段同名身体分别处理。此范围指已收录的身体网格；未来新增角色或第三方换装需要另制对应资源。

每个身体追加 `pbz_breast_l`、`pbz_breast_r`、`pbz_butt_l`、`pbz_butt_r`。女性预设已有的 `breast_l/r`、`butt_l/r` 自动优先匹配这些补充骨骼。全部 LOD 的四根补充骨骼都具有非零蒙皮权重；不同体型的影响范围由身体比例和现有权重计算，少数体型使用更宽的区域。

独立衣物、Chaos 布料和装甲保留原生模拟，未重新制作软组织权重。穿衣角色的外观响应可能被衣物遮挡，需要按体型调节强度与位移上限。资源覆盖与数值正确不等于所有动作、服装穿插和风格均已视觉验收。

## 实现与兼容性

资源使用独立 `/Game/Mods/PBZSoftBones/` 路径，不覆盖原游戏包。保留原有顶点、三角面、材料、UV、法线和原骨骼顺序，追加参考骨骼、LOD 骨骼映射和权重。移除补充副本中与新增权重不一致的旧 Nanite 渲染资源，使显示使用更新后的普通骨骼蒙皮；原游戏资源不变。新增权重从对应父骨的现有权重中拆分；补充骨骼处于参考局部变换时，父子合并后的每个顶点权重与原值完全相同。

运行时创建显示组件并复制原组件动画。原有骨骼调整仍应用于动画源，使头部、头发、衣物和武器挂点继续跟随；只有新增四骨的调整应用于显示组件。源组件只停止蒙皮绘制，保持原本的可见状态，避免外观切换将其误判为过场隐藏。关闭时撤回本功能拥有的修改。

## 碰撞跟随

修改后的最终骨骼姿态通过原生物理更新接口同步到已有运动学碰撞体，位置、旋转和缩放一起更新；关闭变换时恢复。保持原有物理资产策略，不强制传送正在模拟的布娃娃，也不修改共享 PhysicsAsset。

新增四根胸臀骨骼各有一个独立盒形碰撞区域，按资源制作时的影响范围生成，支持 XYZ 分轴缩放。运行时按名称绑定，兼容追加虚拟骨骼的角色。它们跟随当前身体或技能预览身体，继承所属角色主身体的碰撞类型、响应通道和启用状态，不额外发送重叠事件；关闭补充或切换角色时删除。

这些盒体是近似碰撞区域，不是逐顶点碰撞，也不会自动替换独立 Chaos 布料使用的内部碰撞资产。过大缩放仍可能穿过披风、裙子或独立装甲，需要按实际外观调整。

节点存档格式未改变。旧版本忽略新的全局补充开关，不会加载该资源；已有骨骼变换节点的旧版兼容性见 [动画预设](ANIMATION_PRESETS.md)。常规技能预览仍不需要此包；只有缺失胸臀骨骼的补充形变需要它。

UI 为独立实现，只参考 UUEPBS 的分区和滑条交互。没有复制该项目代码或资产；其项目许可证状态见随包的第三方说明。
